# 函数绘图

面向初中和高中函数学习的离线二维函数绘图 PWA。输入函数表达式后即可实时绘图，并支持多函数、参数滑块、自适应采样、交点吸附、坐标投影、本地保存和离线运行。

| 项目 | 说明 |
| --- | --- |
| 正式地址 | <https://lixinseal.github.io/function-drawing/> |
| 源码仓库 | <https://github.com/lixinseal/function-drawing> |
| 运行方式 | 浏览器与 iPad 主屏幕 PWA |
| 题目解析 | 不使用 AI，不连接题目解析服务 |
| 数据保存 | 浏览器本地存储与 JSON 文件 |
| 发布方式 | GitHub Actions 自动构建并发布 GitHub Pages |

## 快速开始

### 直接使用

1. 使用现代浏览器打开正式地址。
2. 在左侧输入表达式，例如 `sin(x)`。
3. 点击“添加函数”。
4. 在画布上拖动、缩放、点击曲线读取坐标。

### 安装到 iPad

1. 在 iPad Safari 中打开正式地址。
2. 点击 Safari 的分享按钮。
3. 选择“添加到主屏幕”。
4. 从主屏幕图标启动一次，等待离线资源缓存完成。
5. 关闭网络后重新启动，确认应用仍可运行。

首次安装和每次获取更新都需要网络。缓存完成后，函数输入、绘图、读数、保存和导出均在 iPad 本地完成。

## 功能概览

### 函数与绘图

- 绘制显式函数 `y=f(x)`
- 同时管理多条函数
- 每条函数单独设置颜色、显示或隐藏、编辑和删除
- 函数列表完全保留在本地，不上传服务器
- 根据屏幕范围和函数形态自适应采样
- 处理无定义区间、断点和数值跳变
- 自动检测 x 轴交点、y 轴交点和函数图像之间的交点
- 提供“适应函数图像”和“重置视图”操作

### 参数与交互

- 识别单字母参数，例如 `a*sin(b*x+c)` 中的 `a`、`b`、`c`
- 参数支持数值输入和滑块调整
- 滑块范围为 `-5` 到 `5`，数值框可输入滑块范围以外的有限值
- 鼠标滚轮围绕指针位置缩放
- 鼠标或单指拖动平移画布
- 双指手势缩放，并以手势中心为缩放锚点
- 双击画布恢复默认视图
- 点击曲线固定读数，再次点击其他位置可更新或取消读数
- 右侧显示函数表达式、`x`、`y` 和数值斜率
- 选中点后绘制到 x 轴和 y 轴的投影辅助线

### 吸附与 Apple Pencil

- 靠近坐标轴交点或函数交点时自动吸附
- 对包含 `sin`、`cos`、`tan` 的函数，吸附到 `kπ/n` 特殊横坐标
- 当前支持的分母为 `1`、`2`、`3`、`4`、`6`
- 吸附后优先显示 `π` 分数形式，例如 `π/2`、`2π/3`
- Apple Pencil 使用比鼠标更大的命中半径，便于精确选择重要点位
- 触控使用较大的命中范围，鼠标使用更严格的命中范围

### 输入与数据

- 内置 `0` 到 `9`、小数点、`+`、`-`、`*`、`/` 快捷输入
- 提供逐字符删除键
- 提供 `sin`、`cos`、`tan`、`sqrt`、`abs`、`ln`、`exp`、幂、`π`、`x` 和括号快捷键
- 自动把当前文档保存到浏览器本地存储
- 支持导出和重新打开 JSON 函数文档
- 支持把当前函数画布导出为 PNG
- 完全不依赖账号、云端数据库或 AI 服务

## 表达式语法

### 变量与常量

- 自变量：`x`
- 参数：除 `x` 外的单个英文字母，例如 `a`、`b`、`k`、`m`
- 常量：`pi`、`e`

### 运算

- 加、减、乘、除：`+`、`-`、`*`、`/`
- 幂：`^`
- 括号：`(`、`)`
- 支持隐式乘法，例如 `2x`、`a(x+1)`、`2sin(x)`

函数名后必须使用括号。例如应写成 `sin(x)`，不能写成 `sin x`。

### 支持的函数

```text
sin cos tan
asin acos atan
sinh cosh tanh
sqrt cbrt abs exp
ln log log10 log2
floor ceil round sign sgn
```

`log` 与 `log10` 均表示常用对数，`ln` 表示自然对数。

### 输入兼容

应用会自动处理以下常见数学写法：

- `π` 转为 `pi`
- `√` 转为 `sqrt`
- `×`、`·` 转为 `*`
- `÷` 转为 `/`
- 数学减号转为 `-`
- 全角数字和全角运算符转为半角字符
- 自动忽略开头的 `y=` 或 `f(x)=`

### 示例

```text
sin(x)
x^2-2*x-3
1/(x-1)
a*sin(b*x+c)
sqrt(4-x^2)
abs(x)
log10(x)
```

## 当前边界

当前版本专注显式函数 `y=f(x)`，以下能力尚未实现：

- 隐式方程，例如 `x^2+y^2=1`
- 不等式区域
- 极坐标和参数方程
- 符号求导、符号积分和方程求解
- 多文档标签页
- 云端同步、账号体系和多设备协作
- AI 题目识别或自然语言解析

右侧“斜率”是通过函数值做数值差分得到的读数，不是符号导数结果。

## 离线与 PWA 机制

- `public/manifest.webmanifest` 定义应用名称、图标、启动地址和独立窗口模式。
- Service Worker 只在生产构建中注册。
- 构建脚本根据 `dist/` 中全部静态资源计算内容哈希。
- 缓存名称格式为 `function-drawing-<hash>`。
- 新 Service Worker 安装时预缓存全部构建资源。
- 激活时只删除同样以 `function-drawing-` 开头的旧缓存。
- 页面导航优先请求网络，以获取更新；网络不可用时回退到已缓存页面和 `offline.html`。
- 脚本、样式、图标等静态资源优先读取缓存，未命中时再请求网络并写入缓存。

因此，更新后的第一次启动需要联网。新版本成功缓存后，后续可以继续离线启动。

## GitHub Actions 发布

工作流文件：

```text
.github/workflows/deploy-pages.yml
```

推送到 `main` 或手动运行工作流后，GitHub Actions 会：

1. 检出仓库
2. 安装 Node.js 22
3. 执行 `npm ci`
4. 执行 `npm run build`
5. 上传 `dist/` 作为 GitHub Pages artifact
6. 发布到固定的 GitHub Pages 地址

仓库不需要提交 `dist/`，也不需要维护 `gh-pages` 分支。

### 首次配置 Pages

仓库管理员需要确认：

1. 打开仓库的 `Settings`。
2. 进入 `Pages`。
3. 在 `Build and deployment` 中把 `Source` 设为 `GitHub Actions`。
4. 确认工作流具有 `pages: write` 和 `id-token: write` 权限。

正式地址始终保持为：

```text
https://lixinseal.github.io/function-drawing/
```

Actions 运行编号和提交哈希会变化，但应用地址不会变化。

### 发布流程

1. 修改 `src/`、`public/` 或配置文件。
2. 本地运行 `npm run build`。
3. 检查构建通过且 `dist/` 资源完整。
4. 提交并推送到 `main`。
5. 等待 `Deploy function drawing PWA` 工作流完成。
6. 打开正式地址验证页面样式、函数列表和画布尺寸。
7. 在 iPad 上联网启动一次，确认新缓存生效。

## iPad 安装与更新

### 新 iPad 首次安装

1. 连接网络。
2. 在 Safari 打开正式地址。
3. 等待页面和图标加载完成。
4. 通过分享菜单添加到主屏幕。
5. 从主屏幕启动，等待首次离线缓存完成。

应用不能通过普通的局域网 HTTP 地址获得完整 PWA 能力。正式安装应使用 GitHub Pages 提供的 HTTPS 地址。

### 已安装设备更新

更新源码并发布成功后：

1. 保持 iPad 联网。
2. 完全关闭主屏幕中的函数绘图应用。
3. 从原主屏幕图标重新打开。
4. 等待页面加载完成。
5. 再次关闭并重新打开，确认新版本已生效。

通常不需要删除主屏幕图标，也不需要重新登录新的 GitHub Actions 地址。必要时可以回到 Safari 打开固定正式地址并手动刷新。

临时刷新参数 `?v=提交哈希` 只用于绕过缓存检查，不是新的应用地址，也不应代替主屏幕图标长期使用。

## 数据与备份

自动保存的数据包括：

- 函数表达式、颜色和显示状态
- 参数值
- 当前视口中心和缩放比例
- 网格、坐标轴和交点开关

自动保存使用浏览器本地存储。清除 Safari 网站数据、卸载 PWA、更换浏览器或迁移到新设备时，本地数据可能丢失。

建议：

- 重要图形使用“保存”导出 JSON。
- 迁移设备前先导出 JSON。
- 需要提交作业或讲义时同时导出 PNG。
- 不要把自动保存视为云端备份。

JSON 文件包含版本号、函数列表、参数、视口和显示开关。导入时会进行结构和数值检查，无效文件会被拒绝。

## 隐私与安全

- 应用不需要账号。
- 不包含 AI 服务或题目上传接口。
- 不包含用户行为统计或广告脚本。
- 函数表达式由本地解析器编译，不使用 `eval`。
- 函数、参数、视口和开关保存在当前浏览器本地。
- 首次加载后，日常使用不需要业务服务器。

## 常见问题

### 页面能打开，但画布显示 `0 × 0` 或没有样式

这通常说明正式地址正在提供仓库根目录的源文件，而不是 Actions 构建后的 `dist/`。

检查：

1. `Settings > Pages > Source` 是否为 `GitHub Actions`。
2. 最新 Actions 的 `build` 和 `deploy` 是否都成功。
3. 浏览器是否仍缓存了旧页面。
4. 线上 HTML 是否引用 `assets/` 中的构建文件，而不是 `/src/main.ts`。

### iPad 更新后仍是旧版本

让 iPad 联网，完全关闭 PWA 后重新打开。Service Worker 会在联网状态下检查更新。若仍未生效，在 Safari 打开正式地址并刷新一次，然后再启动主屏幕应用。

### 输入的表达式提示错误

检查函数名后是否带括号、括号是否成对、参数是否为单个字母。函数定义域外没有实数结果时，图像在该区间不会绘制。

### 看不到某条函数

确认函数列表中的可见开关已打开，表达式没有报错，并点击“适应函数图像”检查当前视图范围。

### 能不能用 `sin x`

不能。当前语法要求写成 `sin(x)`。

### 能不能绘制圆或椭圆

当前只支持 `y=f(x)`。圆和椭圆属于隐式方程，需要后续增加关系绘图引擎。

### 删除主屏幕图标会不会删除函数数据

可能与浏览器站点数据一起被清除。重要文档请先导出 JSON。

### GitHub Actions 的 deploy 一直等待

先取消卡住的运行，再从 Actions 页面执行 `Re-run all jobs` 或手动运行工作流。确认 Pages 源仍为 `GitHub Actions`，并检查同一时间是否存在排队或失败的其他 Pages 部署。

## 与几何绘图的关系

函数绘图与立体几何绘图是两个独立项目，不共享源码、运行数据、Service Worker 缓存或渲染引擎。更新其中一个项目不会改变另一个项目的正式地址和数据。
